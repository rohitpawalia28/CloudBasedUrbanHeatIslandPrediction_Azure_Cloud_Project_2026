Deployment options

Local (default)
python run.py — every service emulated in cloud_runtime/
Hybrid AWS
CLOUD_MODE=aws mirrors S3 objects and SNS messages to your AWS account via boto3
Container
docker compose up --build
Infrastructure as code
infrastructure/terraform/ and infrastructure/cloudformation/ define the real AWS resources
CI
.github/workflows/ci.yml runs the pipeline and API tests on every push

Security controls

  • Raw zone immutable (explicit IAM Deny on delete)
  • SSE-S3 encryption, block-public-access, versioning
  • Salted PBKDF2 passwords, signed expiring tokens
  • Parameterised SQL; read-only query editor
  • Per-identity rate limiting and full access logging
  • No credentials in the repository (.env ignored)
