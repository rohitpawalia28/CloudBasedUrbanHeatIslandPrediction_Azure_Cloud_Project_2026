How the platform uses real AWS

AWS serviceWhat happens
AWS CloudFormationOne template creates every resource below (Infrastructure as Code)
Amazon EC2 + IAM roleThe platform runs on EC2; the instance role grants least-privilege access, no keys stored on the server
Amazon S3Every object written to the data lake (raw, processed, models, predictions) is copied to the real bucket
AWS Lambdauhi-heat-alert-checker runs when new predictions land in S3 (event trigger) and on schedule
Amazon EventBridgeDaily schedule (06:00 IST) that invokes the heat-alert Lambda
Amazon SNSHeat alerts and pipeline alerts are e-mailed through the real topic
Amazon DynamoDBEvery prediction request is stored in table uhi-predictions
Amazon CloudWatchPlatform logs go to /uhi/platform; UHI metrics, an alarm and the UHI-GeoAI-Operations dashboard
AWS Systems ManagerParameter Store /uhi/config tells the platform which resources to use
